# Audio API

The audio API contains the runtime audio system, sources, listeners, and sound resources.

### `include/gallium/core/messagebus.h`

`MessageDataBase`, `MessageBus`, `NAME`, `Internal`

### `include/gallium/audio/sound.h`

`SoundHandle`, `std`

### `include/gallium/audio/audiosystem.h`

`Platform`, `ELoadHint`, `AudioSystem`, `AudioSourceInfo`, `Impl`

### `include/gallium/audio/mixerbus.h`

`MixerBus`, `AudioSystem`, `MixerBusHandle`, `Impl`

### `include/gallium/audio/audioeffect.h`

`IAudioEffect`, `GainEffect`, `LowPassEffect`, `HighPassEffect`

### `include/gallium/audio/audiosource.h`

`ESourceState`, `AudioSource`, `AudioSystem`, `AudioSourceHandle`, `Impl`, `std`
